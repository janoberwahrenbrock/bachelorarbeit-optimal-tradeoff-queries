# Laufdaten

Einzelläufe und Serien speichern ihre Artefakte unter einer eigenen Kennung in
diesem Ordner: eingefrorene Eingaben, Konfigurationen und Profile, Versuche,
Journale, Resultate, Fortschritt und Berichte. Fehlgeschlagene und unterbrochene
Versuche bleiben erhalten.

Nutze die öffentlichen Status-, Resume-, Audit-, Export- und Seal-Befehle aus
dem [Benchmarkverfahren](../docs/benchmarks.md). Verändere keine eingefrorenen
Inputs oder terminalen Resultate von Hand. Ein portables Archiv besitzt ein
eigenes überprüfbares Inventar; siehe [Archive](../docs/seal.md).

Tatsächliche Laufdaten bleiben im Projekt. Sie werden nicht automatisch auf
GitHub geladen und nicht in Wheel/Sdist verpackt. Eine spätere Versionierung
ausgewählter Daten ist eine ausdrückliche separate Entscheidung.
