# Gespeicherte Offlineprüfung

Python 3.13/3.14, Standardbibliothek. Nach der ZIP-Prüfung in ein frisches Verzeichnis entpacken:

python3 -I -S -B studies/d7-a5-n5-h3-grid5-grid-plus-ratio-adaptive-stop-single-candidate-minprog0p001-src72072-group10/reproduction/reproduce.py --project-root /ABS/EXTRACTED --output /ABS/FRESH_ANALYSIS

Die Prüfung kontrolliert gespeicherte wissenschaftliche Originalhashes, Result-/Attempt-/Inputbindungen und reproduziert die öffentliche Tabelle und Formatierung. Native State-/SCI-/Operationsdokumente bleiben private Gates; ihre öffentlichen Projektionen bewahren Originalhashes. Dies ist keine neue Oracle-/Winner-/Raw-/Clean-/Carrier-/Solverprüfung, keine vollständige Offline-SCI und keine neue Messung. Native Partialquellen werden nie als SDK-wholeN5 dargestellt.
